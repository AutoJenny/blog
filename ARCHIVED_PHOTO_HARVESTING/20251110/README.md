# Photo-harvesting Archive

This directory contains archived Photo-harvesting functionality that has been moved out of the main codebase but retained for potential future use.

## Contents

- **utils/**: Photo-harvesting storage utilities
- **static/js/**: Photo-harvesting JavaScript files
- **templates/**: Photo-harvesting HTML templates
- **migrations/**: Photo-harvesting database migrations
- **scripts/**: Photo-harvesting archive scripts

## Note

Links to these files have NOT been updated. If you need to restore Photo-harvesting functionality, you will need to:
1. Move files back to their original locations
2. Update any broken imports/references
3. Re-enable Photo-harvesting in configuration files

## Status

Photo-harvesting is currently inactive but kept in reserve. The main codebase references Photo-harvesting in configuration but the actual implementation files have been archived here.
