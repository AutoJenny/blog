--- 1) Facebook page targeting (platform_credentials) ---

Relevant keys for Facebook (platform_id = Facebook):

  - page_access_token
  - page_id_2         → Page B (CLAN by Scotweb), only used if != page_id

Source: utils/platform_publishers.publish_to_facebook() reads these and builds pages_to_post[];
each call posts to both pages (same content).

To list keys only (run against DB):
  SELECT credential_key FROM platform_credentials
  WHERE platform_id = (SELECT id FROM platforms WHERE name = 'facebook') AND is_active = true;

--- 2) Automated posting switch ---

  - If 'false' or missing: executor skips publishing (logs "Automated posting is DISABLED").
  - Executor defaults to True if key not found.
