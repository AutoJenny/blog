# Product vs Feature Posts - Distinction

**Date:** 2026-01-19  
**Status:** Documentation

---

## Overview

There are two types of product-related posts in `posting_queue`:

1. **`product`** - Automated product posts (new system)
2. **`feature`** - Manual/manually-generated product posts (legacy system)

---

## Product Posts (`content_type='product'`)

### Created By:
- **Script:** `scripts/automated_product_post_creator.py`
- **System:** Automated posting system (runs every 5 minutes)

### Characteristics:
- ✅ **Automated creation** - Created automatically based on `daily_posts_schedule`
- ✅ **Full workflow** - Goes through complete workflow:
  - `format_for_facebook` → `generate_caption` → `add_hashtags` → `optimize_for_facebook` → `publish_to_facebook`
- ✅ **Scheduled** - Has `schedule_name` and proper scheduling
- ✅ **Structured data** - `generated_content` is JSON (structured product data)
- ✅ **Readable caption** - `generated_caption` contains the final Facebook post text

### Example:
```sql
ID: 1336
content_type: 'product'
status: 'ready'
schedule_name: 'Schedule 9'
generated_content: {"category": "product", "product_id": 157044, "product_name": "Clan Crest Pencil Case", ...}
generated_caption: "🏴󠁧󠁢󠁳󠁣󠁴󠁿 Embrace your Scottish pride with our elegant Clan Crest Pencil Case! ..."
```

---

## Feature Posts (`content_type='feature'`)

### Created By:
- **Endpoint:** `POST /launchpad/api/syndication/save-generated-content`
- **System:** Manual content generation in Launchpad UI

### Characteristics:
- ⚠️ **Manual creation** - Created when user generates content in Launchpad UI
- ⚠️ **No workflow** - Does NOT go through automated workflow stages
- ⚠️ **No scheduling** - `schedule_name` is NULL
- ⚠️ **Plain text** - `generated_content` is plain text (readable, not JSON)
- ⚠️ **No caption** - `generated_caption` is typically NULL (not processed)

### Example:
```sql
ID: 655
content_type: 'feature'
status: 'draft'
schedule_name: NULL
generated_content: "🏴󠁧󠁢󠁳󠁣󠁴󠁿🇮🇪 ✨Celtic Oval Belt Buckle - a timeless masterpiece for your wardrobe!💼✨..."
generated_caption: NULL
```

---

## Why Both Exist?

### Historical Context:
1. **Feature posts** were created first - manual content generation in Launchpad
2. **Product posts** were added later - automated system for scheduled posting

### Current State:
- **Feature posts** = Legacy/manual posts (still in queue, but not actively created by automation)
- **Product posts** = Current automated system (actively created and processed)

---

## Key Differences Summary

| Feature | Product Posts | Feature Posts |
|---------|--------------|---------------|
| **Creation** | Automated (script) | Manual (UI) |
| **Workflow** | Full automated workflow | No workflow |
| **Scheduling** | Has schedule_name | No schedule |
| **Content Format** | JSON (structured) | Plain text |
| **Caption** | Generated by workflow | Usually NULL |
| **Status Flow** | draft → ready → pending → published | Stays in draft |
| **Purpose** | Scheduled automated posting | Manual/one-off posts |

---

## Recommendations

1. **For new posts:** Use `product` type (automated system)
2. **For legacy posts:** Feature posts can remain in queue but won't be processed automatically
3. **Cleanup:** Consider migrating or cleaning up old `feature` posts if they're no longer needed
