# How to Publish a Post

**Date:** 2026-02-23  
**Audience:** Content authors, editors

---

## Checklist Before Publishing

1. **All sections drafted** — Every section has content
2. **All sections imaged** — Every section has an image
3. **Publish essentials set:**
   - Title
   - Subtitle
   - Header image
4. **Output readiness** — All required substages complete (see Launchpad Publish Essentials)
5. **Preflight passed** — No blocking issues

---

## Steps

1. Open **Launchpad** in the main navigation
2. Find your post in the publishing area (or calendar week)
3. Expand **Publish Essentials** for your post
4. Confirm Title, Subtitle, Header image are filled
5. Click **Preflight** — checks that all requirements are met
6. If Preflight passes, click **Mark Ready**
7. Click **Publish** to send the post to Clan.com

---

## If Preflight Fails

Preflight lists what's missing. Fix the issues (e.g. add missing image, set header), then run Preflight again.

---

## After Publishing

- Post status becomes `published`
- Post appears on Clan.com
- The post is immutable; edits create new versions or drafts elsewhere

---

## If You See "Output Blocked"

The Launchpad shows **Output Readiness** for each post. If it says "Output not ready", complete the missing substage (e.g. SEO meta, final review). This is separate from "Stage blocked" (workflow stage) and "Automation disabled" (settings).
