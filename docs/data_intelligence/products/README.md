# Products Documentation

**Purpose:** Comprehensive documentation for all product-related systems including profiles, data parsing, and search.

---

## Overview

This directory contains documentation for three main product-related systems:

1. **Product & Category Profiles** (`/profiles/`) - Editorial blog features about products and categories
2. **Product Data Parsing** (`/data/`) - Product type classification and data structure parsing
3. **Product Search** (`/search/`) - Smart semantic search for products
