Substage Management

What is this? Configure which substages (individual steps) appear in your content pipeline for different post types and output channels.

Changes are immediately reflected in the workflow navbar and one-click publication pipeline. Use Post Types to configure the main pipeline, and Output Channels to override for specific channels like Facebook or Instagram.

Post Types Configuration

What it does: Configure which substages (individual steps) are active and in what order for each post type (themed, recipe, profile, etc.). This is the main pipeline configuration that controls what appears in your workflow navbar and one-click publication page.

How to use: Select a post type from the dropdown below, then use the checkboxes to enable/disable substages and drag-and-drop (or edit order numbers) to reorder them within each stage. Click "Save Changes" for each stage when done.

Output Channels Configuration

What it does: Override the default post type substages for specific output channels (blog, Facebook, Instagram, etc.). This lets you create different pipelines for the same content type depending on where it's being published. For example, Facebook posts might skip planning steps and go straight to syndication.

How to use: Select a post type and output channel below. If "Use Post Type Configuration" is checked, it inherits from the Post Types tab. Otherwise, you can configure channel-specific substages. Changes only affect that specific (post_type, output_channel) combination.

Substage Metadata

What it does: View and edit metadata for all available substages in the system. This includes the display label, route function (which page it links to), stage assignment, and display order. This is the master list of all substages that can be assigned to post types.

How to use: Browse the table below to see all substages. Click "Edit" on any substage to modify its label, route function, stage, or order. Use "Add Substage" to create new substages (rarely needed as most are predefined). Changes here affect all post types that use this substage.

Usage Overview

What it does: Provides a comprehensive matrix view showing which substages are used by which post types and output channels. This is useful for understanding the overall configuration and identifying unused or overused substages.

How to use: Use the filters below to narrow down the view by stage or post type. The matrix shows which substages are active (✓) for each post type. This is a read-only overview - make changes in the Post Types or Output Channels tabs.
