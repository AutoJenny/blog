Monitoring System

The monitoring system provides real-time visibility into automation processes, specifically focusing on automated social media postings. It includes a status indicator in the header and a detailed reporting page.

Features

Status Indicator

A traffic light icon in the top-right header shows:

  • 🟢 Green - Monitoring is running
  • 🔴 Red - Monitoring is stopped

The indicator auto-updates every 30 seconds.

Monitoring Report

The report page shows all automation events with filtering:

  • All Events - Everything
  • Automated Postings - Only actual publication events
  • Administrative - Infrastructure/monitoring messages

Event Display

Each event shows:

  • Timestamp (most recent first)
  • Script name
  • Message with full context
  • Result icon (✅ success, ❌ error, ⚠️ warning)

UI Access

Access the monitoring system:

  • Monitoring Report - Full event view
  • Header Indicator - Click the status icon in the top-right of any page

What's Monitored

Automated Postings

These scripts are monitored for actual publication events:

  • automated_weekly_content_creator.log - Weekly content creation
  • automated_weekly_content_workflow.log - Weekly content workflow
  • posting_executor.log - Post execution
  • automated_posting.log - Product posting

Administrative

Infrastructure messages from:

  • background_posting.log - Background monitor status

API Endpoints

  • GET /monitoring/status - Get monitoring status
  • POST /monitoring/start - Start monitoring
  • POST /monitoring/stop - Stop monitoring
  • GET /monitoring/api/events - Get events (with filtering)
