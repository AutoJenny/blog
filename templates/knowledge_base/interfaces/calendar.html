Calendar System

The Calendar System is a comprehensive content planning and scheduling system that manages 52-week content schedules for themes, recipes, profiles, and weekly content (words, phrases, insults). It provides multiple user interfaces for viewing, managing, and scheduling content.

⚠️ Multiple Overlapping UIs: The calendar system currently has multiple user interfaces in various states of completeness. It's unclear which UI is the "current" one. This page documents all available UIs to help navigate and determine which should be primary.

System Overview

Core Concepts

  • 52-Week Structure: Each year is divided into 52 weeks for consistent content planning
  • Cyclic Lists: Base sequences (themes, recipes, profiles, words, phrases, insults) that repeat indefinitely
  • JSON-Backed Display: Fast page loads using pre-computed JSON files (no database queries on display)
  • Week Overrides: Ability to override specific weeks with different items
  • Category-Based: Separate schedules for each content category

Content Categories

The calendar system manages schedules for these content types:

  • Theme - Themed blog posts
  • Recipe - Recipe blog posts
  • Profile Product - Product profile blog posts
  • Profile Surname - Surname profile blog posts
  • Weekly Word - Weekly word social posts
  • Weekly Phrase - Weekly phrase social posts
  • Weekly Insult - Weekly insult social posts
