Unified Channel Preview System

✅ Implemented

The Unified Channel Preview System provides a single, reusable preview mechanism for all social media channels. Any post in Preview or Ready state can be previewed via a standard popup modal, using channel-specific templates and a shared formatter registry.

Core Principle

One preview system, reused everywhere. Preview is HTML-based for all channels.

How It Works

  1. Preview API - Single endpoint: GET /api/preview/post/<post_id>?channel=facebook
  2. Full-Page Preview - Canonical route: GET /preview/post/<post_id>?channel=facebook, used by all Preview buttons (opens in a new tab)
  3. Channel Formatter - Formats content for specific channel (Facebook, Instagram, X, TikTok)
  4. Channel Template - Renders HTML mockup of how post will appear on channel
  5. Universal Modal (Optional) - Reusable modal component that can embed the same preview HTML if needed

Where to Preview

Preview buttons are available in:

  • ✅ Content Control Board - Drill-down panel and Sunday card (opens full-page preview)
  • ✅ Planning Calendar - Week view item cards (opens full-page preview)
  • ✅ Posting Queue - Actions column (can open full-page preview)
  • ✅ Sunday Slot Panel - After generation (opens full-page preview)

Supported Channels

  • Facebook - Full implementation with Facebook-specific formatting
  • Instagram - Stub (uses generic formatting)
  • X/Twitter - Stub (generic + character limit warning)
  • TikTok - Stub (uses generic formatting)
  • Generic - Fallback for unknown channels

Adding a New Channel Template

  1. Create template: templates/channel_previews/<channel>_<type>.html
  2. Create formatter: utils/channel_preview/formatters/<channel>.py
  3. Register formatter in utils/channel_preview/formatters/registry.py
  4. Update template mapping in preview_renderer.py::_get_template_name()

Adding a New Formatter

  1. Create formatter class inheriting from GenericFormatter or implementing format() method
  2. Register in formatters/registry.py
  3. Formatter must return: {'display_text': str, 'char_count': int, 'warnings': List[str], 'meta': Dict}

Technical Details

Preview Renderer: utils/channel_preview/preview_renderer.py
Formatter Registry: utils/channel_preview/formatters/registry.py
API Endpoint: blueprints/channel_preview_api.py
Modal Component: static/js/channel-preview-modal.js

How to Preview a Sunday Deep Dive

  1. Generate a post in the KB Topic Rota Editor
  2. Use the \"Preview\" button to open the full-page preview: /preview/post/<post_id>?channel=facebook
  3. Or preview from Content Control Board or Planning Calendar (week view) using the Preview icons
