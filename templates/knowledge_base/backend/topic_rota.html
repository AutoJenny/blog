KB Topic Rota System

✅ Complete

The KB Topic Rota System is a perpetual, data-driven system that discovers recurring themes from Knowledge Base articles and creates diverse weekly schedules for social media content production.

Overview

This system automatically:

  • Discovers topics from KB articles using unsupervised clustering on semantic embeddings
  • Generates diverse weekly schedules ensuring non-repetitive, interesting content
  • Aggregates content from multiple KB articles for each topic
  • Feeds social media production processes for channel-specific formatting
  • Self-updates automatically when new KB content is added

How It Works

1. Topic Discovery

The system uses clustering algorithms (K-means, DBSCAN, or hierarchical) on KB article embeddings to discover recurring themes. Topics emerge organically from the data - no manual topic lists required.

  • Analyzes all KB article chunks (696 chunks from 629 articles)
  • Groups semantically similar articles into topics
  • Extracts keywords and generates topic names
  • Classifies topic types (practical, historical, cultural, design, product, etc.)

2. Diversity Scheduling

The rota generator ensures non-repetitive, interesting schedules by:

  • Calculating similarity between topics using embedding cosine similarity
  • Scoring diversity based on similarity to recent topics
  • Giving bonuses for different topic types and category areas
  • Enforcing minimum gaps between similar topics

3. Content Aggregation

For each scheduled topic, the system:

  • Retrieves all articles belonging to the topic
  • Ranks article chunks by relevance to topic centroid
  • Selects top chunks and combines them into aggregated content
  • Preserves article structure with clear separators

4. Social Media Production

Topics and aggregated content are exposed via API endpoints for social media production processes:

  • Get weekly topic schedule
  • Retrieve aggregated content for formatting
  • Access topic metadata (keywords, type, articles)

Production processes can then format content for different channels (Facebook, Instagram, Twitter, Blog) while maintaining the core topic and aggregated knowledge.

Database Schema

The system uses 5 database tables:

  • kb_topics - Discovered topics with embeddings and metadata
  • kb_topic_similarity - Pre-computed similarity matrix for diversity
  • kb_topic_rota - Weekly schedule of topics
  • kb_rota_history - History for diversity tracking
  • kb_topic_content - Aggregated content for each topic

API Endpoints

All endpoints are under /api/kb-topics:

  • GET /rota - Get weekly rota schedule
  • GET /<topic_id>/content - Get aggregated content for topic
  • POST /discover - Trigger topic discovery
  • POST /regenerate-rota - Regenerate rota schedule
  • GET /topics - List all topics

Usage

Initial Setup

  1. Run database migration: migrations/20260122_create_kb_topic_rota_tables.sql
  2. Run initial discovery: python scripts/discover_kb_topics.py --method kmeans --compute-similarity
  3. Generate rota: POST /api/kb-topics/regenerate-rota

Ongoing Operation

The system runs automatically:

  • Weekly Discovery: Runs every Monday via background monitor
  • Rota Maintenance: Automatically fills gaps and aggregates content
  • Manual Triggers: Use API endpoints for manual discovery/regeneration

Key Features

  • Unsupervised Discovery: Topics emerge from data, not manual lists
  • Cross-Category Topics: Identifies themes spanning multiple KB sections
  • Diversity Algorithm: Ensures non-repetitive, interesting schedules
  • Perpetual Operation: Self-updates as KB content changes
  • Channel Agnostic: Topics are abstract - formatting happens downstream

Technical Details

  • Embedding Model: intfloat/e5-large-v2 (1024 dimensions)
  • Clustering: K-means (auto-detected k), DBSCAN, or hierarchical
  • Similarity Metric: Cosine similarity between topic embeddings
  • Diversity Constraints: Minimum similarity gap (0.7), 6-week lookback
