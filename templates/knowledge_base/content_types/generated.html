Generated Posts are blog posts that are automatically created using LLM (Large Language Model) technology. These posts are generated from product or category data stored in the system.

What Are Generated Posts?

Generated Posts are blog articles that are automatically created by the system using:

  • Source Data: Product information or category data from the database
  • LLM Generation: Content is generated using Ollama/LLM models
  • Vector Search: Related content is retrieved from the vector index for context
  • Structured Output: Posts include title, standfirst, and multiple sections

Generation Types

The system supports different types of generated content:

  • Deep Dive: Comprehensive article about a product or category
  • Feature: Focused article highlighting specific features
  • Comparison: Comparative analysis between products

How It Works (Current Implementation)

  1. User selects a product or category as the source
  2. System retrieves context from vector index
  3. LLM generates headline, standfirst, and post structure
  4. LLM generates content for each section
  5. Post record is created in draft status
  6. User can review and edit before publication

UI Access

Generated posts can be created through:

  • Content Generation Interface - Generate posts from products/categories
  • Authoring Interface - Review and edit generated posts
