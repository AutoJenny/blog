Facebook Channel

Facebook is the primary social media channel for automated content publishing. The system supports posting to multiple Facebook pages and includes full automation for weekly content.

How It Works

Posting Process

Content is posted to Facebook using the Facebook Graph API:

  1. Content is prepared (image, caption, metadata)
  2. Image is uploaded or made publicly accessible
  3. Post is created via /photos endpoint
  4. Post ID is stored in posting_queue.platform_post_id

Multiple Pages

The system posts to both Facebook pages:

  • Scotweb CLAN - Primary page
  • CLAN by Scotweb - Secondary page

Both pages are posted to simultaneously, with independent success/failure tracking.

Content Types

Facebook currently supports:

  • Weekly Words & Phrases - ✅ Fully automated (words, phrases, insults)
  • Other Content Types - 🔴 Not yet implemented

UI Access

Facebook content can be managed through:

  • Monitoring Dashboard - View posting status
  • Publication Dashboard - Overall publication status

Configuration

Facebook credentials are stored in the platform_credentials table:

  • page_id - Primary page ID
  • page_access_token - Primary page access token
  • page_id_2 - Secondary page ID
  • page_access_token_2 - Secondary page access token

Development Status

✅ Complete

  • Weekly Words & Phrases posting - Fully automated
  • API integration with Facebook Graph API
  • Multi-page posting support (both pages)
  • Image upload and posting
  • Caption formatting with hashtags
  • Error handling and retry logic
  • Posting queue integration

🔴 Planned / Not Implemented

  • Other content types (themed, recipe, profile, generated posts, etc.)
  • Blog post syndication
  • Video posting
  • Story posting
  • Reel posting
  • Engagement tracking
